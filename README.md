근무멍 메인 전환 / 근무북 마지막 순번

- 앱 이름, 홈 화면 아이콘, 시작 화면: 근무멍
- 기본 캐릭터: 근무멍. 기존 근무콩(내부 저장 키 bean)은 근무북으로 변경하고 마지막에 배치
- 근무북 기본색: 연두/연파랑/베이지, 다크모드도 조정
- 기존 데이터 및 기존 커스텀 색상 유지. 근무북 색상을 보려면 색상 기본값 초기화
- 최초 업데이트 시 기존 근무콩 테마 선택 사용자만 근무멍으로 한 번 전환
- 기존 PWA 설치 아이콘은 기기 캐시/재설치 상황에 따라 바로 갱신되지 않을 수 있음


## 2026-10-30 UI 및 게시판 실험 업데이트
- 시작 화면 입력 배치 및 글자 크기 조정, 설정의 반복 설명 일부 숨김
- 게시판 돌아가기 버튼 강조, 친구 전용 로컬 미리보기 게시판 추가
- 게시글·댓글 익명 표시 기능(실제 익명성/접근제어는 서버 구축 후 구현 필요)
- 멍멍이 테스트 친구 답장 `멍멍!` 고정
- 캐릭터별 특수근무 색상과 설정 강조 테두리 보정

주의: 친구 전용 게시판은 현재 **이 기기에만 저장되는 UI 테스트**입니다. 실제 친구와 공유되지 않으며, 온라인 권한 검증이 없습니다.
