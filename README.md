# 근무콩 v1.0 코드 정리본

16단계 기준 **기능·화면·저장 키를 바꾸지 않고** JavaScript를 기능별 파일로 분리했습니다.

## 구조
- `index.html`: 화면 구성 및 순서대로 스크립트 불러오기
- `css/style.css`: 기존 CSS 전체. 우선 시각적 변화가 없도록 기존 우선순위를 보존함
- `js/shifts.js`: 교대 패턴·기준 날짜·근무 계산
- `js/holidays.js`: 공휴일 데이터 조회
- `js/calendar.js`: 달력·메모·패턴 설정
- `js/themes.js`: 테마·색상·시작 화면
- `js/schedule-editing.js`: 연차 차감·날짜 변경·스와이프·설정 토글
- `js/navigation.js`: 탭 이동·첫 실행 안내
- `js/records.js`: 근무 기록·연차 현황·캐릭터
- `js/backup.js`: 데이터 백업·복원
- `calendar-data.js`: 오프라인 공휴일 자료
- `sw.js`: 오프라인 캐시

## 주의사항
- 파일들은 **ES 모듈이 아닌 일반 스크립트**입니다. 위 순서대로 불러오며 전역 변수와 함수를 공유합니다. 순서를 임의로 바꾸면 오류가 날 수 있습니다.
- 기존 `localStorage` 키와 백업 포맷은 변경하지 않았습니다.
- GitHub Pages 업로드 시 **폴더 구조를 유지**해야 합니다. 기존 파일 `script.js`, `style.css`는 새 파일에서 참조하지 않으므로 제거해도 됩니다.
- 기존 CSS에는 중복 선택자가 있으나 마지막 선언이 우선하는 스타일 동작을 보존하려고 이번에는 무리하게 제거하지 않았습니다.
- JavaScript 구문 검사와 파일 참조 검사는 통과했습니다. 실제 iPhone/Android 브라우저의 기능 회귀 테스트는 별도로 필요합니다.
