근무멍 메인 전환 / 근무북 마지막 순번

- 앱 이름, 홈 화면 아이콘, 시작 화면: 근무멍
- 기본 캐릭터: 근무멍. 기존 근무콩(내부 저장 키 bean)은 근무북으로 변경하고 마지막에 배치
- 근무북 기본색: 연두/연파랑/베이지, 다크모드도 조정
- 기존 데이터 및 기존 커스텀 색상 유지. 근무북 색상을 보려면 색상 기본값 초기화
- 최초 업데이트 시 기존 근무콩 테마 선택 사용자만 근무멍으로 한 번 전환
- 기존 PWA 설치 아이콘은 기기 캐시/재설치 상황에 따라 바로 갱신되지 않을 수 있음

## v26 온라인 근무표 공유

`ONLINE_CALENDAR_SHARE_SETUP.sql`을 Supabase 프로젝트 SQL Editor의 **새 쿼리**에서 실행하세요. 기존 SQL을 지울 필요는 없습니다. SQL을 실행하지 않았다면 달력 공유 토글은 작동하지 않습니다.

- 로그인한 두 계정이 온라인 친구인지 확인합니다.
- 친구 프로필 → 설정 → **달력 공유**를 켜야만 상대방이 내 근무표를 볼 수 있습니다. 기본은 비공개입니다.
- 상대방도 같은 설정을 켜야 내가 상대방 근무표를 볼 수 있습니다. 공유 권한은 방향별로 독립적입니다.
- 친구 탭 → **같이 쉬는 날 찾기**에서 공유해 준 친구를 선택해 월별 공통 휴무일을 확인합니다.
- 공유 데이터는 근무 종류만 저장합니다. 개인 메모, 일정 본문, 근무 시간, 연차 차감량, 이메일은 공유하지 않습니다. 다만 **연차라는 근무 상태 자체는 공유**됩니다.
- 수정한 근무표는 앱이 열려 있는 동안 서버에 갱신됩니다. 동기화가 실패하면 다시 로그인하고 온라인 연결을 확인해 주세요.
- 친구 삭제 시 공유 권한은 데이터베이스 트리거로 철회됩니다.
- 첫 실행 설정의 근무 방식은 `----------`에서 시작하고, 기준 날짜는 오늘 날짜입니다. 기존 설정은 건드리지 않습니다.

온라인 SQL을 실행한 뒤에도 **양쪽 실제 계정에서 권한 켬/끔과 공통 휴무일을 확인**해야 합니다. 이 ZIP 생성 단계에서는 실제 서버에서 검증하지 않았습니다.
